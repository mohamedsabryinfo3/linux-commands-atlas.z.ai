# SOC // Linux Deck — مرجع أوامر لينكس لمحللي مركز العمليات الأمنية

صفحة ويب تفاعلية بتصميم هندسي (SOC / Terminal Style) تغطي مسار **SOC Analyst من L1 إلى L2**، مبنية بملف HTML واحد ذاتي الاكتفاء — بدون أي خطوات بناء أو اعتماديات.

## المحتوى

| المسار | الوصف | الحجم |
| --- | --- | --- |
| **TRK-01 — مسار الإتقان** | أهم أوامر لينكس التي يجب أن تحفظها عن ظهر قلب: التنقل، قراءة الملفات، البحث، معالجة النصوص، الصلاحيات، العمليات، الشبكة، والنظام | 81 أمر في 9 فئات |
| **TRK-02 — مرجع SOC** | مرجع قتالي مستقل للرجوع إليه أثناء التحقيقات، مصنف حسب مراحل عمل مركز العمليات: خريطة السجلات، تحليل السجلات، تحليل الشبكة، العمليات والاستمرارية، المستخدمون والمصادقة، فحص البرمجيات الخبيثة، والاستجابة الأولية | 58 بطاقة في 7 مراحل + 12 خط قتال (One-Liners) |

كل أمر يعرض: **اسم الوظيفة** + **شرحاً تفصيلياً** + **مثالاً عملياً قابلاً للنسخ**.

## المزايا التفاعلية

- 🔍 بحث حي فوري في الأوامر والوظائف والشروح (اختصار `/` للتركيز، `Esc` للمسح)
- 🏷️ فلاتر فئات لكل مسار (Chips)
- 📋 نسخ بضغطة للأمر أو للمثال (زر النسخ أو النقر على المثال)
- 💻 محاكاة طرفية حية في الواجهة (Typewriter) تعرض سيناريو تحقيق حقيقي
- 📊 عدادات حية للنتائج وإحصائيات عامة
- 📱 تصميم متجاوب كامل (موبايل / تابلت / سطح مكتب) بواجهة RTL عربية

## التشغيل محلياً

لا يحتاج شيئاً سوى فتح الملف:

```bash
# ببساطة افتح index.html في المتصفح، أو:
python3 -m http.server 8000
# ثم زيارة http://localhost:8000
```

## الرفع على GitHub

```bash
git init
git add .
git commit -m "SOC Linux Deck — interactive Linux commands reference for SOC analysts"
git branch -M main
git remote add origin https://github.com/<username>/soc-linux-deck.git
git push -u origin main
```

## النشر على Vercel

أي طريقة من الثلاثة تكفي:

1. **من الواجهة:** ادخل [vercel.com/new](https://vercel.com/new) واستورد مستودع GitHub — سيكتشف Vercel أنه موقع ثابت تلقائياً وينشره دون أي إعداد.
2. **بالسحب والإفلات:** اسحب مجلد المشروع (أو ملف `index.html`) إلى [vercel.com/new](https://vercel.com/new).
3. **بالأداة:** `npx vercel` من داخل المجلد ثم اتبع الأسئلة.
